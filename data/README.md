# Dataset

The original project uses a road-traffic video (`data.mp4`) collected for the academic prototype. The 565.7 MB source video and generated 554.1 MB output video are intentionally excluded from this repository.

To run the application, upload a compatible `.mp4`, `.avi`, `.mov`, or `.mkv` file through the Streamlit interface. Only use footage that you are authorized to process, and avoid publishing identifiable license plates without a lawful basis.

The small CSV files under `evaluation/data/` are retained as research artifacts. They are not an independently labelled benchmark dataset; see `docs/project-report-summary.md` for the evaluation caveat.
